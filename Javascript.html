1. Introduction to JavaScript

⏱️ 6 min read 🔰 Beginner

What is JavaScript?

JavaScript is a programming language that adds interactivity to websites. It was created in 1995 and has become one of the most popular programming languages in the world.

💡 Key Point: JavaScript is not related to Java. They're different languages with similar names!

What can JavaScript do?

  • ✨ Change HTML content and attributes
  • 🎨 Modify CSS styles dynamically
  • 👀 Respond to user actions (clicks, typing, mouse movements)
  • ✅ Validate form data before sending to server
  • 🌐 Fetch data from servers (AJAX/Fetch API)
  • 🎮 Create animations and games

JavaScript Example

// This is a comment - JavaScript ignores this
// Display a popup message
alert('Hello, World!');

// Change HTML content
document.getElementById('demo').innerHTML = 'Text changed by JavaScript!';

// Respond to clicks
function buttonClicked() {
    console.log('Button was clicked!');
}

Where to Put JavaScript

1. Internal JavaScript (in HTML file)

<!DOCTYPE html>
<html>
<head>
    <script>
        // JavaScript goes here
        function sayHello() {
            alert('Hello!');
        }
    </script>
</head>
<body>
    <button onclick="sayHello()">Click Me</button>
</body>
</html>

2. External JavaScript (separate file)

<!-- In HTML file -->
<script src="js/script.js"></script>

<!-- In script.js file -->
function sayHello() {
    alert('Hello from external file!');
}

2. Variables & Data Types

⏱️ 8 min read 🔰 Beginner

What are Variables?

Variables are containers for storing data values. Think of them as labeled boxes where you can put information.

📦 Analogy: A variable is like a labeled box. You put something in it, and you can look inside whenever you need it.

Declaring Variables in JavaScript

Keyword Description Example
var Old way (function-scoped) - avoid using var name = "John";
let Modern way (block-scoped, can be reassigned) let age = 25;
const Constant (cannot be reassigned) const PI = 3.14;

JavaScript Data Types

📝
String

Text data

let name = "Alice";
🔢
Number

Integers & decimals

let age = 25;
✅
Boolean

true or false

let isStudent = true;
📦
Array

List of items

let colors = ["red", "blue"];
📋
Object

Key-value pairs

let person = {name: "John"};
🚫
Null

Intentional empty

let data = null;

typeof Operator

Use typeof to check a variable's type:

let name = "Sarah";
console.log(typeof name); // "string"

let score = 95;
console.log(typeof score); // "number"

let isLoggedIn = true;
console.log(typeof isLoggedIn); // "boolean"

4. Conditionals (if/else)

if Statement

The if statement executes code only if a condition is true.

let age = 18;

if (age >= 18) {
    console.log("You can vote!");
}

if...else Statement

let temperature = 25;

if (temperature > 30) {
    console.log("It's hot outside!");
} else {
    console.log("It's not too hot.");
}

if...else if...else

let score = 85;

if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F");
}

Switch Statement

let day = "Monday";

switch(day) {
    case "Monday":
        console.log("Start of week!");
        break;
    case "Friday":
        console.log("Weekend almost here!");
        break;
    case "Saturday":
    case "Sunday":
        console.log("Weekend!");
        break;
    default:
        console.log("Regular day");
}

5. Loops

for Loop

Run code a specific number of times:

// Count from 1 to 5
for (let i = 1; i <= 5; i++) {
    console.log("Count: " + i);
}

while Loop

Run while a condition is true:

let i = 1;
while (i <= 5) {
    console.log("Number: " + i);
    i++;
}

do...while Loop

Run at least once, then while condition is true:

let i = 1;
do {
    console.log("This runs at least once");
    i++;
} while (i <= 3);

Looping Through Arrays

let fruits = ["apple", "banana", "orange"];

// for loop
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

// for...of loop (simpler!)
for (let fruit of fruits) {
    console.log(fruit);
}

6. Functions

What are Functions?

Functions are reusable blocks of code that perform specific tasks.

Function Declaration

function greet(name) {
    return "Hello, " + name + "!";
}

// Call the function
let message = greet("Alice");
console.log(message); // "Hello, Alice!"

Function Expression

const square = function(x) {
    return x * x;
};

console.log(square(5)); // 25

Arrow Functions (Modern)

// Shorter syntax!
const add = (a, b) => a + b;

const multiply = (a, b) => {
    let result = a * b;
    return result;
};

console.log(add(5, 3));      // 8
console.log(multiply(4, 2)); // 8

Parameters vs. Arguments

  • Parameters: Variables listed in function definition
  • Arguments: Values passed when calling the function
// 'a' and 'b' are parameters
function add(a, b) {
    return a + b;
}

// 5 and 3 are arguments
add(5, 3);

8. Objects

What are Objects?

Objects store collections of key-value pairs. They represent real-world entities with properties.

// Create an object
let student = {
    firstName: "John",
    lastName: "Doe",
    age: 20,
    isEnrolled: true,
    grades: [85, 92, 78]
};

// Access properties
console.log(student.firstName);  // "John"
console.log(student["lastName"]); // "Doe"
console.log(student.age);         // 20

// Modify properties
student.age = 21;
student.grades.push(95);

Object Methods

Objects can also contain functions (methods).

let car = {
    brand: "Toyota",
    model: "Camry",
    year: 2020,
    start: function() {
        console.log("Car started!");
    },
    getInfo() { // Shorthand syntax
        return `${this.brand} ${this.model}, ${this.year}`;
    }
};

car.start();
console.log(car.getInfo());

Looping Through Objects

let person = {name: "Alice", age: 25, city: "New York"};

// Get keys
console.log(Object.keys(person));   // ["name", "age", "city"]

// Get values
console.log(Object.values(person)); // ["Alice", 25, "New York"]

// Loop through properties
for (let key in person) {
    console.log(`${key}: ${person[key]}`);
}

9. DOM Manipulation

What is the DOM?

DOM (Document Object Model) is a programming interface for HTML documents. It represents the page as a tree of objects that JavaScript can manipulate.

💡 With JavaScript, you can change HTML content, attributes, styles, and even add/remove elements!

Selecting Elements

Method Description Example
getElementById() Select by ID document.getElementById("header")
getElementsByClassName() Select by class document.getElementsByClassName("card")
getElementsByTagName() Select by tag document.getElementsByTagName("p")
querySelector() Select first match (CSS selector) document.querySelector(".card")
querySelectorAll() Select all matches document.querySelectorAll("p.intro")

Changing Content

// Change text content
document.getElementById("demo").textContent = "New text!";

// Change HTML content (can include tags)
document.getElementById("demo").innerHTML = "<strong>Bold text</strong>";

// Change attributes
document.querySelector("img").src = "new-image.jpg";
document.querySelector("a").href = "https://example.com";

// Change styles
document.getElementById("box").style.color = "red";
document.getElementById("box").style.backgroundColor = "blue";

Creating and Adding Elements

// Create new element
let newDiv = document.createElement("div");
newDiv.textContent = "I'm new!";
newDiv.className = "box";

// Add to page
document.body.appendChild(newDiv);

// Insert before another element
let parent = document.getElementById("container");
let reference = document.getElementById("reference");
parent.insertBefore(newDiv, reference);

// Remove element
let element = document.getElementById("to-remove");
element.remove();

10. Events

What are Events?

Events are actions that happen in the browser that JavaScript can respond to: clicks, key presses, mouse movements, form submissions, etc.

Common Events

Event Description Example
click Element clicked button.onclick = function() {}
mouseover Mouse enters element element.onmouseover
mouseout Mouse leaves element element.onmouseout
keydown Key pressed input.onkeydown
submit Form submitted form.onsubmit
load Page loaded window.onload
input Input value changed input.oninput

Adding Event Listeners

Method 1: Inline (not recommended)

<button onclick="alert('Clicked!')">Click</button>

Method 2: Property

let btn = document.getElementById("myButton");
btn.onclick = function() {
    alert("Button clicked!");
};

Method 3: addEventListener (best)

let btn = document.getElementById("myButton");
btn.addEventListener("click", function() {
    alert("Button clicked!");
});

// Can add multiple listeners
btn.addEventListener("click", function() {
    console.log("This also runs!");
});

Event Object

Event handlers receive an event object with information about the event.

document.getElementById("myInput").addEventListener("keydown", function(event) {
    console.log("Key pressed:", event.key);
    console.log("Target element:", event.target);
    
    if (event.key === "Enter") {
        console.log("Enter pressed!");
    }
});
