1. Introduction to HTML

⏱️ 5 min read 🔰 Beginner

What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page using markup.

💡 Key Point: HTML is not a programming language - it's a markup language that tells the browser how to structure content.

HTML Elements

An HTML element is defined by a start tag, some content, and an end tag:

<tagname>Content goes here...</tagname>

Example:

<h1>My First Heading</h1>
<p>My first paragraph.</p>

HTML Tags

HTML tags are element names surrounded by angle brackets:

  • <tagname> - opening tag
  • </tagname> - closing tag (with forward slash)
  • Some tags are self-closing (void elements): <br>, <hr>, <img>
Common HTML Tags
Tag Description Example
<h1> - <h6> Headings (h1 most important, h6 least) <h1>Title</h1>
<p> Paragraph <p>Text</p>
<a> Anchor (link) <a href="url">Link</a>
<img> Image (self-closing) <img src="image.jpg">

2. Basic Document Structure

⏱️ 8 min read 🔰 Beginner

HTML5 Document Template

Every HTML document follows a basic structure. Here's the minimal template you need:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first web page.</p>
</body>
</html>

Breaking It Down:

<!DOCTYPE html>
Declares that this is an HTML5 document (must be first line)
<html>
The root element of the HTML page
<head>
Contains meta-information about the document (not displayed)
<title>
Specifies a title for the page (shown in browser tab)
<body>
Contains the visible page content

4. Text Formatting

Formatting Elements

HTML provides several tags for formatting text:

Tag Description Example Result
<b> Bold text <b>This is bold</b> This is bold
<strong> Important text (semantic) <strong>Important!</strong> Important!
<i> Italic text <i>Italic text</i> Italic text
<em> Emphasized text <em>Emphasized</em> Emphasized
<mark> Marked/highlighted text <mark>Highlight</mark> Highlight
<small> Smaller text <small>Small text</small> Small text
<del> Deleted text <del>Deleted</del> Deleted
<ins> Inserted text <ins>Inserted</ins> Inserted
<sub> Subscript H<sub>2</sub>O H2O
<sup> Superscript E=mc<sup>2</sup> E=mc2

💡 Semantic vs. Presentational: Tags like <strong> and <em> describe the meaning of text, while <b> and <i> only describe style. Use semantic tags when possible!

5. Links & Images

HTML Links (Anchor Tags)

Links are created with the <a> tag. The link destination is specified in the href attribute.

<a href="https://www.example.com">Visit Example</a>
<a href="page2.html">Relative Link</a>
<a href="#section-id">Link to Section</a>
<a href="mailto:email@example.com">Email Me</a>

Link Examples:

  • Absolute link (goes to another website)
  • Relative link (stays on same site)
  • Email link
  • Opens in new tab (target="_blank")

HTML Images

Images are defined with the <img> tag (self-closing).

<img src="image.jpg" alt="Description of image" width="300" height="200">

Important Attributes:

  • src - Source file path (required)
  • alt - Alternative text (required for accessibility)
  • width/height - Dimensions (optional but recommended)

6. HTML Lists

Unordered Lists

Use <ul> for bulleted lists:

<ul>
    <li>First item</li>
    <li>Second item</li>
    <li>Third item</li>
</ul>

Output:

  • First item
  • Second item
  • Third item

Ordered Lists

Use <ol> for numbered lists:

<ol>
    <li>First step</li>
    <li>Second step</li>
    <li>Third step</li>
</ol>

Output:

  1. First step
  2. Second step
  3. Third step

Nested Lists

You can nest lists inside lists:

<ul>
    <li>Fruits
        <ul>
            <li>Apples</li>
            <li>Bananas</li>
        </ul>
    </li>
    <li>Vegetables
        <ul>
            <li>Carrots</li>
            <li>Broccoli</li>
        </ul>
    </li>
</ul>

Output:

  • Fruits
    • Apples
    • Bananas
  • Vegetables
    • Carrots
    • Broccoli

Description Lists

Use <dl> for terms and descriptions:

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
    <dt>CSS</dt>
    <dd>Cascading Style Sheets</dd>
</dl>

Output:

HTML
HyperText Markup Language
CSS
Cascading Style Sheets

7. HTML Tables

Table Structure

Tables are defined with the <table> tag. They're perfect for displaying tabular data.

<table>
    <caption>Student Grades</caption>
    <thead>
        <tr>
            <th>Student</th>
            <th>Assignment</th>
            <th>Grade</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>John Doe</td>
            <td>HTML Project</td>
            <td>A-</td>
        </tr>
        <tr>
            <td>Jane Smith</td>
            <td>HTML Project</td>
            <td>A</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="2">Average Grade</td>
            <td>A-</td>
        </tr>
    </tfoot>
</table>

Output:

Student Grades
Student Assignment Grade
John Doe HTML Project A-
Jane Smith HTML Project A
Average Grade A-

Merging Cells: colspan & rowspan

colspan Example (merge columns):

<table border="1">
    <tr>
        <th>Name</th>
        <th colspan="2">Phone Numbers</th>
    </tr>
    <tr>
        <td>John</td>
        <td>123-4567</td>
        <td>890-1234</td>
    </tr>
</table>
Name Phone Numbers
John 123-4567 890-1234

rowspan Example (merge rows):

<table border="1">
    <tr>
        <th rowspan="2">Department</th>
        <th>Employee</th>
    </tr>
    <tr>
        <td>John Smith</td>
    </tr>
</table>
Department Employee
John Smith

📚 Lecture Connection: This matches the HTML Tables lecture notes (p. 6-7) where we learned about colspan and rowspan for complex table layouts.

Table Styling with CSS

While HTML defines table structure, CSS makes them look good:

<style>
    table {
        border-collapse: collapse;
        width: 100%;
    }
    th {
        background-color: #3498db;
        color: white;
        padding: 12px;
    }
    td {
        padding: 8px;
        border: 1px solid #ddd;
    }
    tr:nth-child(even) {
        background-color: #f2f2f2;
    }
    tr:hover {
        background-color: #e9e9e9;
    }
</style>

This creates the striped, hoverable tables you see throughout our site!

8. HTML Forms

Form Structure

Forms collect user input using the <form> tag:

<form action="/submit-form" method="post">
    <!-- Form elements go here -->
</form>

Common Input Types

Input Type HTML Code Example
Text field <input type="text">
Password <input type="password">
Email <input type="email">
Number <input type="number">
Checkbox <input type="checkbox"> Subscribe
Radio button <input type="radio"> Option A
Submit button <input type="submit">
Textarea <textarea></textarea>
Select dropdown <select><option>...</select>

Complete Form Example

<form>
    <fieldset>
        <legend>Personal Information</legend>
        
        <label for="name">Full Name:</label>
        <input type="text" id="name" name="name" required>
        
        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>
        
        <label>Gender:</label>
        <input type="radio" name="gender" value="male"> Male

9. Semantic HTML

What is Semantic HTML?

Semantic HTML uses tags that clearly describe their meaning to both the browser and developer.

❌ Non-Semantic

<div id="header">...</div>
<div class="nav">...</div>
<div id="main">...</div>
<div class="article">...</div>
<div id="footer">...</div>

✅ Semantic HTML5

<header>...</header>
<nav>...</nav>
<main>...</main>
<article>...</article>
<footer>...</footer>

HTML5 Semantic Elements

Element Description
<header> Introductory content or navigation links for a section
<nav> Set of navigation links
<main> Main content of the document (unique per page)
<article> Self-contained, independent content (blog post, news story)
<section> Thematic grouping of content
<aside> Content indirectly related to the main content (sidebar)
<footer> Footer for a document or section
<figure> Self-contained content like images, diagrams, code listings
<figcaption> Caption for a <figure>
<time> A specific time or date
<mark> Highlighted text

11. HTML Validation

Why Validate Your HTML?

  • Ensures cross-browser compatibility
  • Improves accessibility
  • Makes debugging easier
  • Better SEO performance
  • Professional code quality

W3C Validator

The W3C provides a free validation service: validator.w3.org

Common Validation Errors to Avoid:

Error Solution
Missing alt attribute on image Always add alt text
Duplicate IDs IDs must be unique per page
Nested <a> tags Don't put links inside links
Missing <li> in lists List items must be direct children of <ul> or <ol>
<table> without <tbody> Use proper table structure
