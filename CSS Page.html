1. Introduction to CSS

⏱️ 5 min read 🔰 Beginner

What is CSS?

CSS (Cascading Style Sheets) is the language used to style HTML documents. It controls colors, fonts, layouts, and visual presentation.

💡 Analogy: HTML is the skeleton, CSS is the skin, clothes, and makeup!

CSS Syntax

A CSS rule consists of a selector and a declaration block:

selector {
    property: value;
    property: value;
}

Example:

h1 {
    color: blue;
    font-size: 24px;
    text-align: center;
}

p {
    color: #333;
    line-height: 1.6;
}

Three Ways to Add CSS

1. Inline CSS

Using the style attribute directly on HTML elements.

<h1 style="color: red;">Hello</h1>

Inline styled

2. Internal CSS

Using <style> tag in the document head.

<style>
    h1 { color: blue; }
</style>

Internal styled

3. External CSS

Linking to a separate .css file (best practice).

<link rel="stylesheet" 
      href="style.css">

External (linked)

5. Box Model

Understanding the Box Model

Every element in CSS is a rectangular box with four areas:

Margin (outside border)
Border
Padding
Content

Box Model Properties:

  • Content: The actual content (text, image, etc.)
  • Padding: Space between content and border (transparent)
  • Border: Surrounds padding and content
  • Margin: Space outside the border (transparent)
div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 30px;
}

/* Individual sides */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

/* Shorthand (top right bottom left) */
padding: 10px 20px 10px 20px;
/* top/bottom left/right */
padding: 10px 20px;

.container {
    display: flex;           /* or inline-flex */

    align-self: center;      /* Override align-items */

10. Responsive Design

What is Responsive Design?

Responsive design ensures websites look good on all devices - desktop, tablet, and mobile.

"Responsive Web Design is about using HTML and CSS to automatically resize, hide, shrink, or enlarge a website, to make it look good on all devices."

Viewport Meta Tag

<meta name="viewport" content="width=device-width, initial-scale=1.0">

This tells browsers to set the viewport width to the device width.

Media Queries

Media queries allow you to apply CSS only when certain conditions are met.

Resize the browser to see me change! 
/* Mobile first approach */
.container {
    width: 100%;
    padding: 10px;
}

/* Tablet styles */
@media (min-width: 768px) {
    .container {
        width: 750px;
        margin: 0 auto;
    }
}

/* Desktop styles */
@media (min-width: 1024px) {
    .container {
        width: 960px;
    }
}

/* Orientation */
@media (orientation: portrait) {
    /* Styles for portrait mode */
}

/* Print styles */
@media print {
    .no-print {
        display: none;
    }
}

Common Breakpoints

  • Mobile: up to 480px
  • Tablet: 481px - 768px
  • Small desktop: 769px - 1024px
  • Large desktop: 1025px and above

11. CSS Transitions

What are Transitions?

Transitions allow you to change property values smoothly over a given duration.

Hover over me!

Transition Properties

Property Description Example
transition-property Which property to transition all, background-color, transform
transition-duration How long the transition takes 0.3s, 500ms
transition-timing-function Speed curve of transition ease, linear, ease-in, ease-out
transition-delay Delay before transition starts 0.1s, 1s

Timing Functions

linear
ease
ease-in
ease-out
ease-in-out
/* Transition shorthand */
.box {
    transition: all 0.3s ease 0s;
}

/* Individual properties */
.box {
    transition-property: background-color, transform;
    transition-duration: 0.3s, 0.5s;
    transition-timing-function: ease, ease-out;
    transition-delay: 0s, 0.1s;
}

/* Different transitions for different states */
.box:hover {
    background-color: red;
    transform: scale(1.1);
}

12. CSS Animations

What are Animations?

Animations allow you to create complex, keyframe-based animations without JavaScript.

✨

Keyframes

@keyframes animation-name {
    0% {
        /* styles at start */
    }
    50% {
        /* styles at middle */
    }
    100% {
        /* styles at end */
    }
}

/* You can also use from/to */
@keyframes slidein {
    from {
        transform: translateX(0);
    }
    to {
        transform: translateX(100px);
    }
}

Animation Properties

Property Description Example
animation-name Name of @keyframes bounce, slidein
animation-duration How long animation takes 2s, 500ms
animation-timing-function Speed curve ease, linear, ease-in
animation-delay Delay before start 0.5s
animation-iteration-count Number of times to run 3, infinite
animation-direction Direction of animation normal, reverse, alternate
animation-fill-mode Styles before/after animation forwards, backwards
bounce
pulse
spin
shake
/* Animation shorthand */
.element {
    animation: bounce 2s ease-in-out 0s infinite alternate;
}

/* Individual properties */
.element {
    animation-name: bounce;
    animation-duration: 2s;
    animation-timing-function: ease-in-out;
    animation-delay: 0s;
    animation-iteration-count: infinite;
    animation-direction: alternate;
}
